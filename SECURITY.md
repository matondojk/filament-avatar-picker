# Security Policy

## Supported Versions

Only the latest major version of this package is actively supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| 1.x     | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within this package, please send an e-mail to MatondoJK via [matondo@example.com](mailto:matondo@example.com) instead of using the issue tracker.

All security vulnerabilities will be promptly addressed.
